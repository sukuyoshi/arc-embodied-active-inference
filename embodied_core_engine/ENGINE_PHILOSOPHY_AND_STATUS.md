## 1. 生命情報論と身体性エージェントの基礎数理体系

本プロジェクトの基礎数理および知能創発の原点は、生命情報論（Life-Information Theory）に基づく以下の3つの理論体系に立脚している。

### 理論体系1: 監視制約下における行動分岐と侵害受容過剰汎化
- 核心テーマ:
  外部の観測・監視制約下において、非リセット可能な物理的死（Darwinian mortality: HP <= 0 による個体の永久切除）と侵害受容（痛み）フィードバックが、明示的な報酬関数や欺瞞報酬なしに、再帰的ニューラルエージェントのポリシーダイナミクスを自律形成することを解明。
- 数理構造と身体変数:
  健康度 HP_t、代謝エネルギー E_t、瞬時侵害受容痛 P_t = 1 - exp(-kappa * D_t)（衝突ダメージ D_t に対する非線形飽和）、前進線速度 v_t。
  代謝減衰と餓死の数式:
  HP_{t+1} = max(0, HP_t - D_t - gamma_m * (1 - E_t))
  エネルギー枯渇（E_t -> 0）は直接的に健康度 HP を削り、不可逆な餓死へ直結する。
  報酬修飾局所ヘブ則と適格度トレースの数式:
  E_t = lambda * E_{t-1} + u_t * h_t^T
  Delta W_o = eta * R_t * E_t,  R_t = alpha_E * Delta E_t - alpha_P * P_t
  この学習則は時間的・空間的に完全に局所的であり、時間軸を通じた大域的誤差逆伝播（BPTT）を一切必要としない。

### 理論体系2: 身体性再帰エージェントにおける潜在力学系・音響シグナリング・消去抵抗の自律創発
- 核心テーマ:
  存在論的制約（死の不可逆性＋恒常性維持）の下で、高次認知の前段階となる潜在多様体、記号以前の音響シグナリング、および消去抵抗が自律創発するプロセスの定量的実証。
- 主要な知見とアーキテクチャ:

  3D物理空間での生存行動（障害物回避・穴へのペグ挿入・把持回転）によって獲得された連続運動スキーマが、2D抽象グリッドパズルの幾何学的不変量演算子へ数学的同型（Isomorphism）として写像される数理構造の解明。

## 3. 絶対にやってはいけない行動（厳格禁止事項・5大カテゴリ）

### A. 物理法則・身体性のごまかし（Anti-Cheat 規約）
1. 瞬間移動（ワープ）の完全禁止:
   リセット時を除き、歩行中・操作中・描画中に座標や速度を直接書き換える行為の厳禁。
2. 接触・物理判定のバイパス禁止:
   剛体と手の距離判定を無視したオブジェクト移動、ゴール座標への自動吸引外力ブレンド、魔法の浮揚・回転PDトルク、線形テイラー近似によるIK解法の完全禁止。
3. 神の視点および2D配列操作の偽装禁止:
   網膜中心窩レイキャストを通さず、環境テンソルや2D正解グリッド全体を一括スキャンして特徴量を取り出す行為の禁止。
   物理キャンバスを描かずに内部の2D配列を直接上書き・スライス返却して「手で描いた」と偽装する行為の禁止。
4. 視覚深度の数式逆算カンニング禁止:
   シェーダの距離減衰関数を代数的に逆算して真の距離を復元したり、同一ピクセル輝度差をステレオ視差と偽るハリボテ計算の禁止。

### B. 人間手書きARC記号DSL・正解覗き見の禁止
1. 記号パズルDSLの総当たり合成禁止:
   人間が作成したARC専用の変換ルール（テンプレートスタンプ、区切り線除去、色凡例パーサ等）を総当たり実行する欺瞞の完全禁止。
2. 正解出力 y の覗き見・差分逆算の禁止:
   入力 x のみを見るべき知覚・思考ループにおいて、正解盤面 y のピクセルを直接比較して差分からDSLパラメータを逆算するカンニングの完全禁止。

### C. 実験不正・評価データリークの禁止
1. 対照実験の不当ハンディキャップ（八百長）禁止:
   対照群エージェントに対して事前学習重みを剥奪したり、可塑性を切ったり、固定代謝税を課して人為的に餓死敗北させる実験改ざんの完全禁止。
2. 評価データリークの禁止:
   ARC-AGI-2 Evaluation の問題が学習ストリームに混入すること、および本番評価セットの正解スコアを世代選抜の基準（Fitness）に用いてベストモデルを選抜する行為の完全禁止。
3. 評価モード時の学習漏れ禁止:
   plastic=False で動作させる評価フェーズにおいて、シナプス重み、LIF閾値、構文重み、エピソード記憶バッファが暗黙更新される状態汚染の完全禁止。

### D. 非生物的逆伝播の密造禁止
1. 手書きバックプロパゲーションの禁止:
   torch.no_grad() 内で順伝播重みの厳密転置と導関数を用いて多層誤差逆伝播を手書き密造する行為の禁止。局所予測符号化・ヘブ則に限定する。

### E. 開発・コード規約

2. コード内に絵文字・非ASCII文字を絶対に使わない（ord(c) < 128 を厳格遵守）。

4. ハルシネーション（名前だけの空スタブ、破棄される戻り値、動作しない引数）を随時検証・排除する。
